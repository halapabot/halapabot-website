Built for streamers

Data first.
AI second.

HalapaBot is a streamer-focused control center that brings Twitch, OBS, voice, memory, moderation, analytics and AI-assisted workflows into one local desktop application.

The goal is not to make AI the center of your stream. The goal is to give AI the context it needs to be useful.

How it works

Context before action.

HalapaBot is built around a simple chain: collect the information the application actually has, understand that context, then use AI, rules or automation where they add value.

01 — DataWhat is actually happening?
Twitch activity, stream state, chat, configured services and other available signals.
02 — ContextWhat does it mean here?
Relevant history and current state are considered before a response or action.
03 — DecisionShould anything happen?
Commands, rules, AI and automation are separate tools for the same stream context.
04 — ActionDo the useful thing.
Respond, control, remember, moderate, analyze or prepare content.

Features

What is actually inside the app?

HalapaBot is not one screen. The desktop application is a control center with dedicated workspaces and settings for different parts of the stream.

CONTROL CENTER

Overview

See the health of the Bot/API, Twitch and AI service, control the bot process and inspect recent chat messages.

CONNECTIONS

Twitch & AI connections

Manage the streamer account, bot account and AI provider connection in one place.

VOICE

Voice Control Center BETA

Microphone, listening mode, wake phrase, speech language, Whisper model, execution mode and command groups.

OBS / AUTOMATION

OBS & Automatic Clipping BETA

Scene and automation controls plus highlight candidates and OBS Replay Buffer capture.

MEMORY

Memory Manager

Control memory-related behavior and keep relevant information available across sessions.

MODERATION

Moderation Center

Configure and inspect context-aware moderation workflows and moderation actions.

ANALYTICS

Analytics

Review stream and chat analytics in a dedicated workspace as the analytics layer evolves.

CONTENT WORKSPACE

Review, history & publishing readiness

Review locally archived content, edit content packages, approve them for publishing readiness and archive approved items. Publishing does not start automatically.

PERFORMANCE

Performance Overlay

Expose CPU, RAM and GPU information as a separate safe overlay. FPS/frametime is not presented as game-hooking telemetry.

SETTINGS

Themes, accents & language

Dark, Ash, Light and Summer base themes plus Midnight, Neon, Aurora, Graphite, Fire and Summer accents, alongside UI and chat-language controls.

App tour

See the real application.

The screenshots below are taken from the current HalapaBot UI evidence in the project workspace. They are here to explain what users actually see, not to invent a marketing mock-up.

Overview

The first screen answers three questions immediately: is the local API reachable, is Twitch connected and which AI service is selected?

  • Bot/API connection state
  • Twitch connection state
  • AI service state
  • Bot start/stop controls
  • Recent Twitch chat

Voice Control Center

Voice is deliberately configurable. The user chooses the microphone, language, Whisper model and execution mode instead of assuming one universal setup.

  • Local Whisper runtime
  • Small / Medium / Large-v3 model choices
  • Automatic / CPU / NVIDIA GPU execution paths where supported
  • Wake word and listening state
  • Command groups — including the separately marked OBS BETA group

Command groups

Turning a group off does not disable the entire Voice Engine. It only prevents that category of voice command from being processed.

  • Stream & Twitch
  • OBS & Automation — BETA
  • Audio
  • Moderation
  • HalapaBot
  • Memory
  • Assistant

Automatic Clipping

Clipping uses OBS Replay Buffer. A candidate is not treated as a completed clip until OBS confirms the save.

  • Highlight threshold
  • Cooldown
  • Clip duration
  • Pre-roll / post-roll
  • Candidate state and capture status

Settings & appearance

The application exposes visual and runtime preferences rather than hiding them in an opaque configuration file.

  • UI language
  • Bot chat language
  • Dark / Ash / Light / Summer
  • Midnight / Neon / Aurora / Graphite / Fire / Summer
  • Window style and motion-related preferences
